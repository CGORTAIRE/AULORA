## Reglas

- Nadie sube directo a `main`: cada uno trabaja en su rama y abre un Pull Request.
- Otro compañero revisa el Pull Request antes del merge.
- Atributos privados con `__` y acceso con `@property`.
- Horas como texto `"HH:MM"`.
- Antes de trabajar: `git pull` en `main`.
